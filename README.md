# Расписание КФУ им. Вернадского — бот + сайт

Парсит официальный сайт https://cfuv.ru/raspisanie/ через его же JSON-API
(`GET /wp-json/cfu/v1/sched/index` и `/group?code=...`), а не HTML.
Нужен только Python 3.10+, зависимостей нет.

```
kfu-raspisanie/
  parser.py         — общий парсер + кэш (.cache/): группы, поиск, форматирование
  schedule_image.py — рендер дня/недели в PNG: темы day ☀️ / night 🌙 (нужен Pillow)
  bot.py            — Telegram-бот (факультет → направление → курс → группа + ввод кода)
  web.py            — сайт http://localhost:8000 (те же данные, выбор факультета и группы)
  docs/             — frontend сайта (index.html / style.css / app.js)
```

Картинки: `pip install Pillow` (уже стоит, если бот запускается на этом ПК).
Без Pillow бот честно пишет об этом и отвечает текстом.

## 1. Проверка парсера (без токена)

```powershell
cd kfu-raspisanie
python -c "import parser; g=parser.get_group('ПИ-б-о-241'); print(len(g['занятия']))"
```

## 2. Telegram-бот

1. Создай бота у [@BotFather](https://t.me/BotFather) → получи токен
   (после `/revoke` старый токен умирает — нужен свежий).
2. Сохрани токен в файл `token.txt` рядом с `bot.py`
   (только токен, без лишнего; файл уже в `.gitignore`, никому его не показывай).
   Либо, как вариант, в ТОМ ЖЕ окне терминала:
   `$env:KFU_BOT_TOKEN='твой_токен'`
3. Запусти и не закрывай окно, пока нужен бот:

```powershell
cd kfu-raspisanie
python -u bot.py
# должен написать «Бот запущен» и число групп; окно не закрывать
```

Что умеет бот:
- /start — выбор: институт → направление → курс → группа (кнопки)
- просто прислать код: `ПИ-б-о-241` — сразу покажет неделю
- просто прислать фамилию: `Парменов` — расписание преподавателя 👤
- /my — моя сохранённая группа на сегодня ⭐
- /now — что идёт сейчас и следующая пара 🟢
- /today, /tomorrow, /week, /even (чётная), /odd (нечётная), /group КОД
- /sess — сессия и экзамены 📝 (как опубликуют на сайте)
- /pic — сегодня картинкой 🖼, /picweek — неделя картинкой 🖼
- /ics — файл календаря `.ics` для телефона 📅
- /teacher ФАМИЛИЯ — расписание преподавателя
- /theme или кнопка 🌙/☀️ — день/ночь со звёздами (у каждого своя)
- кнопки «п/г: все/1/2» — расписание своей подгруппы
- /notify on|off или кнопка ⏰ — слать пары утром в 07:00 МСК
- /changes on|off — сообщать, что именно поменялось в расписании 🔄
- кнопки ◀ ▶ листают дни, 🖼 переключает текст/картинка
- запоминает группу, тему, подгруппу и подписки каждого пользователя

Сайт: вкладки «Группа» / «Преподаватель», кнопка 🌙 — ночная звёздная
тема с созвездием-гербом КФУ (щит, звезда, книга, грифоны, «КФУ» —
всё из точек-звёзд; мерцание, уважает reduced-motion), фильтры
Сегодня / Сейчас 🟢 / Неделя / чёт-нечёт, фильтр подгруппы,
кнопка 📅 скачивает `.ics`, блок сессии (когда опубликуют),
ссылки вида `#g=ПИ-б-о-241` открывают сразу группу — можно делиться.
Дополнительно в ссылке: `#theme=night` (сразу ночная тема),
`#side=both|left|right|center` (герб с обеих сторон / слева / справа / по центру).

## 3. Сайт

```powershell
cd kfu-raspisanie
python web.py
# открыть http://localhost:8000
```

Селекты подразделение → направление → курс → группа + строка поиска кода,
фильтры Сегодня / Завтра / Неделя / Чётная / Нечётная. Последняя группа
запоминается в браузере.

## 4. GitHub Pages (сайт в интернете, бесплатно)

Фронт в `docs/` — чистая статика: на `*.github.io` скрипт ходит напрямую
в API вуза (CORS открыт), а `.ics` собирает прямо в браузере. Бэкенд не нужен.

1. На странице репозитория: Settings → Pages → Source: Deploy from a branch →
   ветка `main`, папка `/docs` → Save.
2. Через минуту сайт живёт тут: `https://remageht.github.io/cfuv-schedule/`

Локально (`web.py`) ничего не меняется: скрипт сам понимает, где запущен
(на Pages — прямые запросы, дома — через прокси; принудительно:
`?api=direct` или `?api=local`).

## Как это устроено

- `parser.get_index()` — 15 подразделений, ~590 групп, звонки, чётные/нечётные недели, кэш 6 ч.
- `parser.get_group('ПИ-б-о-241')` — занятия: день (1=Пн..6=Сб), пара (1..8),
  чётность (обе/чёт/нечёт), предмет, вид, преподаватели, аудитория, корпус,
  подгруппа (0=вся группа, 1/2).
- `parser.find('teacher'|'room'|'subject', запрос)` — поиск пар по сайту, кэш 1 ч.
- Утренняя рассылка живёт в процессе бота (поток, 07:00 МСК): для работы
  ночью окно с `bot.py` должно быть запущено.
- `web.py` — прокси: браузер ходит на `/api/*` того же origin,
  а Python уже ходит на cfuv.ru (напрямую из браузера мешает CORS).
